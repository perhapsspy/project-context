# 목표

- 최근 `project-context` 관련 문서 정리 실패/교정 사례를 케이스별 사실 문서로 다시 조사하고, 그 근거로 스킬 개선안을 실제 스킬에 반영한다.

## 범위

- 케이스 문서는 사실 조사만 담는다.
- 각 케이스는 별도 파일 하나로 기록한다.
- `project-context`가 다루는 문서 작업을 사건 기준으로 삼는다.
- 코드 수정, 성능 조사, 배포가 본 사건인 케이스는 분석 대상에서 제외한다.
- 하위 에이전트는 서로 다른 증거 축을 독립적으로 조사한다.
- 개선안은 케이스 분류와 하위 에이전트 리뷰를 거쳐 별도 문서로 쓰고, 합의된 최소 항목만 스킬에 반영한다.

## 현재 상태

- 하위 에이전트 6개 축의 사실 조사 결과를 받아 `cases/` 아래 32건으로 분리했다.
- 각 케이스 첫머리를 사용자 지적/요청, 에이전트 조치, 드러난 문제 순서로 다시 고쳤다.
- 코드 수정 중심 케이스 12건은 `archive/code-related-cases/`로 옮겼다.
- `SKILL-IMPROVEMENT-PROPOSAL.md`에 반복 문제, 반영 후보, 제외할 범위, 하위 에이전트 리뷰 반영 내용을 정리했다.
- `skills/project-context/SKILL.md`와 설치본 `project-context` 스킬에 기준 문서 풍화 방지, 기존 담당 표면 확인, 완료 전 미추적 파일/설치본 확인 문장을 반영했다.
- 하위 에이전트 리뷰에서 나온 표현 모호성, 결정 로그 모순, `.DS_Store` 미분류 지적을 반영했다.
